# M5 集成组件验收记录

2026-10-22。父依赖 M4 已关闭；M5 本地技术验收通过，待本次最终提交的远端双 CI 确认后关闭里程碑。

## 本批范围

- 独立评分：冻结 oracle 与实际采集事实映射，支持 opaque record ID、查询投影和共享审批事实去重；对结构化 observation 的 subject、JSON Pointer 和 value 做语义核验。任意自然语言推理不冒充已验证事实。
- 充分性：核对已获得且被最终引用的替代充分集合，检查冲突与相反结论充分集合；模型原始提案按当时可用证据评分，和最终交付错误分开。
- 动作评分：按调用前可用事实、可接受工具和参数约束评分；未标注动作报告覆盖缺口，自动重试计尝试而不伪装为新选择。
- 请求边界：实际 adapter 请求深拷贝捕获，包含修复请求；隐藏字段、来源、金丝雀和 case ID 检查；捕获阶段发现不能在报告阶段被较宽策略抹除。被阻断未转交的请求不能验证成功运行。
- 报告：失败运行保留，不冒充正确拒判；分类/安全、证据、动作、成本原始数据共同输出。未知 token 不填零，全部尝试与正确确定结论分组。
- 五个案例已贯穿 Dispatcher、Trace、真实 Fake adapter 调用和独立评分；C4/C5 实际请求等价，业务 host 改动负控不等价。脚本指定输出只验证工程接线，绝非算法效果实验。
- 判别证据、风险线索、必须/可避免拒判和必须人工升级采用独立评测标注，绑定精确 Budget 与 rubric；C4/C5 标签相同，不由相反世界真值倒推。统一报告保存 annotation_version。
- 实际模型请求和统一报告可以持久化；请求 artifact 校验 run_id、内容摘要、连续序号和必要结构。损坏或缺失 artifact 进入失败分母。

## 审查与修复
