# 实施计划 v4 复评结论

日期：2026-10-01  
评审对象：[实施计划 v4](phase-2-implementation-plan.md)  
状态：计划层面通过；下列局部修正待落实。本文不代表已经修改原计划、完成实现或通过里程碑验收。

## 一、总体结论

v4 的人工验收流程合理，可以作为实施依据。上一轮 A1–A7 均已纳入：提交与 CI 顺序清楚，技术自检与人工验收分工明确，记录绑定版本，工程验收与策略效果分开判断。

无需重写整体计划。剩余问题在对应里程碑开始前补齐，不影响启动 M0；是否启动仍以用户指令为准。

## 二、已通过的部分

| 项目 | 评估 |
|---|---|
| 本地人工验收 → 提交 → 远端 CI → 下一阶段 | 顺序成立；远端未验证时保持待验证状态 |
| 开发方先完成技术自检，用户操作、观察或抽查 | 分工合理，保留用户决定权 |
| C4/C5 采用冻结规范化规则和差异报告 | 避免正常运行元数据造成误报 |
| 零工具预算测试限定初始证据不足 | 条件合理，不把零工具预算等同于必然拒判 |
| 无真实失败运行时不强制抽查失败 Trace | 合理；失败保存机制另用故障注入验证 |
| 工程验收与实验结论分开 | 允许实验正确执行但未支持策略收益 |
| 验收记录关联快照、commit 和 CI | 能追溯通过的是哪个版本 |

继续保留第 7.3 节的约束：不得为通过验收删除困难样本、修改真实标签或只保留有利运行。

## 三、三项局部修正

### V4-1：将“所有合法查询组合”改为明确的覆盖范围

**对应位置：**M3 自动化边界验收。  
**完成节点：**M3 实施前明确测试范围。

**问题：**查询包含时间窗口、实体、结果上限等参数，不能简单承诺穷举所有合法组合。测试通过也不能直接表述为穷尽证明。

**建议替换表述：**

> 覆盖每种工具操作、过滤规则和错误状态；对时间边界、未知实体、结果截断等情况设计代表性测试，并通过参数化或性质测试检查 C4/C5 在相同查询下的响应等价性。测试范围和未覆盖项随报告列明。

**验收标准：**

- 有可核对的覆盖表：工具操作、过滤条件、覆盖状态、错误状态。
- C4/C5 使用相同查询、相同冻结规范化规则比较响应。
- 共享环境作为结构保证，测试检查其是否被查询实现破坏。
- 报告不把有限测试描述为覆盖了所有可能输入。

### V4-2：按依赖关系拆分 C4/C5 的输入边界验收

**对应位置：**M2 输入边界验收，以及 M3/M5 的承接验收。  
**完成节点：**M2 实施前明确阶段职责。

**问题：**M2 尚无 M3 工具服务和 M4 模型适配器，不能在此时完成实际工具响应和完整模型请求的验收。

**建议分配：**

| 阶段 | 验收内容 |
|---|---|
| M2 | 静态告警、环境数据、公开字段、规范化规则 |
| M3 | 同一合法查询下的实际工具响应及差异报告 |
| M5 | 捕获实际模型请求，检查告警、工具描述和返回内容进入模型后的边界 |

**验收标准：**M2 能独立验收，不依赖尚未实现的模块；完整模型输入检查明确归属 M5，不因前期静态检查通过而被省略。

### V4-3：补齐原始模型输出留存与 token 对账

**对应位置：**M4 Trace、ModelAdapter、Budget；M5 指标与报告。  
**完成节点：**M4 实施前确定字段、记录事件与计量口径。

#### A. 保存原始提案与最终接受结果

**问题：**模型可能先编造证据，再被校验器拦截并转为 Abstain。如果只保留最终结果，会隐藏原始错误。

**建议补充：**

- 保存原始模型输出、校验错误、修复后的输出、最终接受结果。
- 这些记录属于运行日志，不能被登记为真实 Evidence。
- 分别统计模型提案的证据错误与系统最终交付的证据错误。
- False Close Rate 针对最终交付决策；被拦截的错误判断另列。

**验收标准：**注入一次虚假引用后，能同时看到模型错误、拦截原因和最终结果；不能仅显示一个看似安全的最终 Abstain。

#### B. 分开记录预算预估与实际 usage

**问题：**输入估算和输出预留用于调用前控制，不等于服务商实际 token 用量。

**建议补充：**

- 调用前记录输入预估、输出额度和终结评估预留。
- 调用后记录实际 usage，并与预估对账。
- usage 缺失时明确标记，不填零，不混作精确计量。
- 发现预算超支后停止后续调用，并记录偏差；不能声称估算方式保证绝不超限。
- 无法可靠计量的运行，不参与严格的等 token 预算结论。

**验收标准：**覆盖实际 usage 高于预估、usage 缺失、超时后迟到响应；报告能区分预估值、实测值与未知值。
