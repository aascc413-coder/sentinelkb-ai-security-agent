# SentinelKB 项目验收报告

验收日期：2026-08-12

运行方式：Windows 11 + Python 3.12 + Docker Desktop + Neo4j 5.26.28

运行模式：离线模式（不依赖大模型 API Key）

## 验收结论

SentinelKB 的核心业务链路已经贯通，可以作为一个完整的 AI 安全知识库原型进行本地演示：

`安全文档上传 → 文档解析与分块 → 检索索引 → IOC/ATT&CK 抽取 → Neo4j 图谱 → 可追溯问答 → 安全研判工作台`

## 自动化测试

- Pytest：14 项全部通过。
- 检索烟雾评测：10 个小型合成问题，Recall@1、Recall@3、MRR 均为 1.0。
- 评测边界：该结果仅说明固定演示数据可正确检索，不能表述为生产环境准确率。

## 交付入口

- `启动项目.cmd`：启动 Neo4j，等待其健康后启动 FastAPI。
- `关闭项目.cmd`：停止 Neo4j，但保留图谱数据卷。
- `验收项目.cmd`：自动验证健康、问答、安全研判、检索索引和知识图谱。
- 控制台：<http://localhost:8080>
- API 文档：<http://localhost:8080/docs>
- Neo4j Browser：<http://localhost:7474/browser/>

## 已知边界

- 离线问答返回检索到的可追溯原文，不等同于大模型生成回答。
- 当前 ATT&CK 映射和风险评分属于可解释规则，覆盖演示场景，不代表完整生产规则库。
- 当前是单机原型，正式生产部署仍需身份认证、租户隔离、密钥管理、审计、恶意文件检测和监控告警。
