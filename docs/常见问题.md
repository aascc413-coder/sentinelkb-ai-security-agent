# SentinelKB 常见问题

## 浏览器提示 localhost 拒绝连接

说明 FastAPI 尚未运行或已经退出。确认 Docker Desktop 已启动、`启动项目.cmd` 窗口没有关闭，并检查终端是否显示 `Uvicorn running on http://127.0.0.1:8080`。

## 健康页显示在线，但问答失败

`mode: online` 只表示配置已加载。常见原因包括模型名错误、账号无权限、余额不足或中转站限流。根据页面中文错误提示和运行终端最后一段日志判断，配置方法见 [国内模型服务配置指南](国内模型服务配置指南.md)。

## 文档一直显示“正在处理”

在线入库可能同时执行文档解析、知识抽取、图谱写入和 Embedding，耗时会受文件大小与模型服务影响。

- 小型 TXT 超过 90 秒仍未完成：查看运行终端错误。
- 只有对话模型权限：设置 `DISABLE_LOCAL_EMBEDDINGS=1` 后重启。
- 返回 `429`：降低操作频率，检查中转站限额。
- 重复文件：系统按内容哈希识别，不会重复入库。

## Neo4j Browser 的账号密码

本地演示默认用户名为 `neo4j`，密码为 `password`，地址为 <http://localhost:7474/browser/>。该密码仅用于本机演示，正式部署必须修改。

## 为什么没有 Embedding 也能问答

项目提供持久化词法检索和 Neo4j 图谱检索兜底。Embedding 能提升语义召回，但不是启动与演示核心链路的强制条件。

## 如何正确关闭

1. 在运行 API 的终端按 `Ctrl+C`。
2. 双击 `关闭项目.cmd`。
3. 等脚本结束后再关闭 Docker Desktop。

关闭脚本不会删除 Neo4j 数据卷。
